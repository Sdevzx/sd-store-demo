# 🛒 SD STORE (Demo Version)

ยินดีต้อนรับสู่โปรเจกต์ **SD STORE Demo** เว็บไซต์ร้านค้าออนไลน์เวอร์ชันทดสอบที่พัฒนาด้วย Stack เทคโนโลยีที่ทันสมัย รวดเร็ว และปลอดภัย เพื่อแสดงศักยภาพของระบบจัดการร้านค้าและการเชื่อมต่อฐานข้อมูลที่มีประสิทธิภาพ

🌐 **เข้าชมเว็บไซต์เวอร์ชันเดโม:** [https://storex.sdevzx.online](https://storex.sdevzx.online)

---

## 🚀 ฟีเจอร์เด่นภายในระบบเดโม (Features)

* **Modern Auth System:** ระบบเข้าสู่ระบบที่ปลอดภัย ดึงข้อมูลโปรไฟล์ผู้ใช้งานได้ทันที
* **Dynamic UI/UX:** หน้า Welcome Screen และระบบจำลองการเปลี่ยน Layout สลับเข้าหน้าร้านค้าอย่างไร้รอยต่อ (ไร้การ Refresh หน้าเว็บ)
* **Dark Mode Design:** ตกแต่งหน้าตาเว็บด้วยดีไซน์คุมโทนสีเข้ม (Slate/Gray Palette) สบายตา ดูพรีเมียมด้วย Tailwind CSS
* **Global State Management:** ใช้ความสามารถของ `useState` ในการแชร์สถานะผู้ใช้และข้อมูลระบบข้ามคอมโพเนนต์อย่างเสถียร

## 🛠️ เทคโนโลยีที่ใช้พัฒนา (Tech Stack)

* **Frontend & Fullstack Framework:** [Nuxt 3](https://nuxt.com/) (Vue 3 / Composition API)
  ![Nuxt JS](https://img.shields.io/badge/Nuxt-002E3B.svg?style=for-the-badge&logo=nuxt&logoColor=#00DC82)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/)
  ![TailwindCSS](https://img.shields.io/badge/tailwindcss-%2338B2AC.svg?style=for-the-badge&logo=tailwind-css&logoColor=white)
* **Database ORM:** [Prisma](https://www.prisma.io/)
  ![Prisma](https://img.shields.io/badge/Prisma-3982CE?style=for-the-badge&logo=Prisma&logoColor=white)

  ![Postgres](https://img.shields.io/badge/postgres-%23316192.svg?style=for-the-badge&logo=postgresql&logoColor=white)
